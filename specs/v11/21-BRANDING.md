### Requirement 21: Branding (Logo and Favicon)

**User Story:** As the product owner, I want the RevoTask logo and favicon on every page where the application is named, so that the product looks the same in the browser tab, the Sidebar, the sign-in pages, and the header.

#### Acceptance Criteria

New in V11 (Decision X). No API, data model, or permission changes.

1. [BRAND-01] THE Frontend SHALL serve the Favicon_File from `frontend/app/favicon.ico` through the Next.js file convention, so that `GET /favicon.ico` returns HTTP 200 with a content type of `image/x-icon` or `image/vnd.microsoft.icon`.
2. [BRAND-02] THE Frontend SHALL leave the `<link rel="icon">` to Next.js, so that the rendered `<head>` of every page contains exactly one `link` element with `rel="icon"` and `href="/favicon.ico"`, and `app/layout.tsx` contains no manual icon `<link>` and no `metadata.icons` entry.
3. [BRAND-03] THE Frontend SHALL keep Logo_Mark at `frontend/public/brand/logo-revo.svg` and Logo_Full at `frontend/public/brand/logo-text-revo.svg`, and SHALL refer to them only by the absolute paths `/brand/logo-revo.svg` and `/brand/logo-text-revo.svg`, written only in `BrandLogo`.
4. [BRAND-04] THE Frontend SHALL render every logo through `BrandLogo` in `components/shared/` with the variants `mark` (Logo_Mark) and `full` (Logo_Full), and feature components, pages, and layouts SHALL import `BrandLogo` and SHALL contain no raw `<img>` element and no other `next/image` use for the logo.
5. [BRAND-05] THE BrandLogo SHALL render with `next/image` and the `unoptimized` prop, because the Next.js image optimizer does not process SVG and rejects it unless `dangerouslyAllowSVG` is enabled; THE Frontend SHALL leave `dangerouslyAllowSVG` unset and SHALL add no `images` entry to `next.config.ts`.
6. [BRAND-06] THE BrandLogo SHALL pass `width` and `height` equal to the `viewBox` of the file (480 by 480 for `mark`, 540 by 165 for `full`) so that the browser reserves the aspect ratio before the file loads, SHALL set the displayed size with token-backed size classes (Requirement 14, criterion 9), and SHALL display `mark` at no more than 480 CSS pixels wide and `full` at no more than 540 CSS pixels wide, so that the Embedded_Raster is never enlarged.
7. [BRAND-07] THE BrandLogo SHALL give the image the alt text `RevoTask`, and WHERE the logo sits inside a control that has its own accessible name, or next to visible text that reads RevoTask, THE BrandLogo SHALL render `alt=""` through a `decorative` property.
8. [BRAND-08] WHILE the viewport is 960 pixels or wider, THE Frontend SHALL show in the Sidebar toggle `BrandLogo` with the variant `full` when the Sidebar is expanded, and the variant `mark` with the tooltip `RevoTask` when it is collapsed; THE toggle SHALL stay a button named "Collapse sidebar" or "Expand sidebar" with `aria-expanded`, THE Sidebar SHALL drop the separate text "RevoTask" because Logo_Full contains the wordmark, and below 960 pixels THE off-canvas drawer SHALL show `full` at the top without a toggle button.
9. [BRAND-09] THE Frontend SHALL show `BrandLogo` on the login and register pages in the brand panel (variant `full`, replacing the placeholder tile and the small text) and in the form card header below 960 pixels (variant `full`), and WHILE a logo is shown on the brand panel gradient, THE Frontend SHALL place it on a `bg-surface-raised` tile with a radius token, because the Embedded_Raster has an opaque background (Open Question 21).
10. [BRAND-10] WHILE the viewport is below 960 pixels and the page is not a Board, THE App_Header SHALL show the link to `/boards` as `BrandLogo` (variant `mark`, `decorative`) followed by the visible text RevoTask, so that the link name stays "RevoTask".
11. [BRAND-11] THE Frontend SHALL keep the title `RevoTask` in the root `metadata` and the suffix "· RevoTask" in the page titles, and SHALL add no `app/icon`, `app/apple-icon`, or `app/manifest` in V11, because the owner supplied only `favicon.ico` (Open Question 20).
12. [BRAND-12] THE BrandLogo and the elements around it SHALL use only token-backed utilities (Requirement 14, criterion 9), with no hex colour, no Tailwind default palette colour, and no arbitrary value.
13. [BRAND-13] THE Frontend SHALL load the favicon and every logo from its own origin, so that a page makes no request to a third-party host for them.
14. [BRAND-14] WHEN the Brand_Assets are moved, THE implementation SHALL use a plain move (the three files are untracked, so `git mv` does not apply), SHALL leave no copy of any Brand_Assets file in `frontend/images/` or elsewhere, and SHALL remove the empty `frontend/images/` directory.
15. [BRAND-15] THE BrandLogo SHALL be a Server Component without state or event handlers (Decision H and the Server Component rule), SHALL pass `loading="eager"` because every logo sits above the fold, and SHALL NOT use the deprecated `priority` property.
16. [BRAND-16] THE System SHALL treat the Brand_Assets files as replaceable in place: a later true-vector SVG with the same file name and `viewBox` replaces the Embedded_Raster file with no change to Frontend code.
17. [BRAND-17] THE System SHALL verify the branding with these checks: (a) Playwright: `GET /favicon.ico` returns 200 with an icon content type, and the page `<head>` has the one icon link; (b) Playwright: on `/login` at 1280 pixels and at 360 pixels the visible logo image has `alt` `RevoTask` (or `alt=""` beside the text RevoTask) and a `naturalWidth` above 0 after load; (c) Playwright: no request in the page's network log goes to a host other than the application's own origin and the API origin; (d) `vitest`: `BrandLogo` renders `mark` and `full` with the right `src`, `width`, `height`, alt text, and `decorative` behaviour; (e) `vitest`: the Sidebar shows `full` when expanded and `mark` with the tooltip RevoTask when collapsed; (f) `vitest`: no component or page except `BrandLogo` contains the strings `/brand/` or `<img`, and `BrandLogo` contains no hex colour; (g) `vitest`: `frontend/images/` does not exist, or exists with no files; (h) no `waitForTimeout` in the new Playwright tests (Requirement 15, criterion 3).
